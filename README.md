# kindle-csv-bookmarklet
Skryptozakładka eksportująca całą bibliotekę Kindle ze strony Amazon „Zarządzaj zawartością i urządzeniami” do pliku CSV: tytuły, autorzy, rozmiar, data dodania, urządzenia, kolekcje i status przeczytania. Działa w przeglądarce, z paskiem postępu, bez wtyczek i bez podawania hasła.
